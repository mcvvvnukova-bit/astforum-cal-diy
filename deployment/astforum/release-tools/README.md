# Исторические инструменты релизов VPS

Исходники из /opt/astforum-cal-diy/releases, сохранённые 1 октября 2026 года. Они привязаны к конкретным версиям, путям и условиям соответствующей публикации. Это архив кода; не запускать его как универсальную команду развёртывания. Исходники самого приложения представлены историей коммитов этого PR. Секреты, runtime.env, сборки, снимки записей и базы исключены. На VPS проверены 6102 исходных файла активного релиза: они совпадают с текущим checkout форка.
